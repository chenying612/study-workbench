# 学习工作台

一款面向中小学生的个人学习管理工具，纯网页实现，无需注册、数据本地存储，支持安装为桌面/手机应用（PWA），离线也能用。

## 功能模块

- **目标管理**：设立学习目标、跟踪完成进度
- **作业管理**：按科目记录每日作业，支持完成状态标记、完成时间记录、自定义日历视图（完成/逾期/假期一目了然）
- **成绩记录**：记录各科考试成绩，自动生成按科目分类的正确率趋势折线图，直观掌握学习走势
- **课程表**：每周课表管理，支持自定义时间段、工作日/周末分区、课程颜色标记，可导出课表截图
- **专项突破**：针对薄弱环节的专项练习进度追踪
- **错题本**：错题收录与复习管理

## 特点

- 🔒 **数据私有**：所有数据存储在本地浏览器，不上传任何服务器
- 📴 **离线可用**：PWA 技术支持断网使用，安装后像普通 App 一样运行
- 💾 **备份恢复**：一键导出/导入 JSON 备份，换设备不丢数据
- 📱 **多端适配**：Mac / Windows / 手机浏览器均可使用

## 快速开始

### 本地使用

在项目目录启动静态服务器：

```bash
python3 -m http.server 8899
```

浏览器访问 `http://localhost:8899/学习工作台.html`，或直接双击项目内的 `启动学习工作台.command`（macOS）一键启动。

> 注意：PWA 功能（安装、离线）要求 HTTPS 或 localhost 环境，直接双击 HTML 文件（file:// 协议）时不可用。

### 在线使用（GitHub Pages）

直接访问在线地址，无需安装任何环境：

**https://chenying612.github.io/study-workbench/学习工作台.html**

打开后可安装为应用，离线使用：

- **Mac / Windows（Chrome、Edge）**：地址栏右侧点击安装图标，或浏览器菜单 →「安装学习工作台」，安装后出现在启动台/开始菜单，可独立窗口运行
- **iPhone / iPad（Safari）**：点击分享按钮 →「添加到主屏幕」
- **安卓（Chrome）**：浏览器菜单 →「添加到主屏幕」或「安装应用」

> 每个人的数据存储在自己的浏览器中，互不影响；换设备时使用「导出备份 / 导入恢复」迁移数据。

## 文件说明

| 文件 | 说明 |
|------|------|
| `学习工作台.html` | 主应用（单文件，包含全部页面、样式和逻辑） |
| `manifest.json` | PWA 应用清单 |
| `sw.js` | Service Worker（离线缓存） |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | 应用图标 |
| `启动学习工作台.command` | macOS 一键启动脚本 |

## 数据说明

- 所有数据存储在浏览器的 localStorage 中，每台设备独立
- 使用应用内的「导出备份 / 导入恢复」功能可在设备间迁移数据
